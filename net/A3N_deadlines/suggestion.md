# WHAT IS THIS THING?
This contains several files for the deadlines.
### 1. deadlineID.A3
This file contains the ID of the deadlines, so that the
Arancia 3 Network Service Provider (That one you see in users.js) will
help you fill everything up and pass the deadline.
### 2. devices.A3
This contains the supported devices (like the A3S), just to let them
notify you about the deadline.
### 3. isonline.A3
This says if the service is online or not. It's
also included in the root of the repo.
### 4. serve.A3
Contains the hash for the deadlines. The A3N Service Provider will
spit random Hashes, and if the hash that spits is equal to the
account's hash, get up. Sign this deadline.
### status.A3
contains a number. Very useful for testing.
### verify.A3
This says if there's a wave of deadlines incoming.
#### That's all.
